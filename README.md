# USB Bridge

Интернет компьютера → USB → Android → точка Wi‑Fi. Windows-программа работает из распакованной папки. Android-приложения: USB Bridge и WireRoute.

## Скачать и запустить

Откройте [последний релиз](https://github.com/Nikita15313/usb-bridge/releases/latest), скачайте `USBBridge-Windows-0.15.6.zip` и распакуйте целиком. Этот выпуск обновляет только Windows-программу. Уже установленные USB Bridge 0.15.5 и WireRoute 3.1.11 на телефоне оставьте.

1. На компьютере откройте `USBBridge.exe` из распакованного архива.
2. Для первой установки на другом телефоне комплект 0.15.5 находится в предыдущем релизе. WireRoute 3.1.9 из него предназначен только для обновления 3.1.8 или более старой версии. Если уже установлен WireRoute 3.1.10, 3.1.11, 3.1.12 или новее — сохраните его. Удалять приложения ради установки не нужно.
3. Подключите кабель, выберите «USB-модем»; если Windows его не видит — «MIDI».
4. Нажмите «Подключить» в USB Bridge на телефоне и компьютере.
5. VPN включается в WireRoute телефона. Раздача включается кнопкой «Включить Wi‑Fi» в USB Bridge.

Другим устройствам нужны имя сети и пароль. Режим «Без VPN» относится к VPN телефона: VPN самого компьютера остаётся частью выбранного источника.

## Рабочий ПК без USB ADB-драйвера

В Windows 0.15.6 добавлен отдельный вариант для случая, когда USB-интернет работает, а телефон не виден для ADB. Подготовьте телефон на домашнем ПК с работающей разрешённой USB-отладкой: остановите подключение в программе, откройте «Подключение» → «Подготовить дома» и подтвердите действие после чтения условий.

На рабочем ПК выберите на телефоне «USB-модем». Если программа уже подключается, нажмите «Остановить», затем откройте «Подключение», включите «Использовать подготовку дома на этом ПК», сохраните и подключитесь. При первом обращении с рабочего ПК Android может запросить разрешение ключа этого компьютера. Подтвердите его на телефоне. Через MIDI этот способ не работает.

Эта подготовка явно включает legacy TCP-отладку на порту 5555. Канал отладки не шифруется; доступ защищён разрешением ключа компьютера, а порт может быть доступен и на других интерфейсах телефона. Подготовка требует отдельного согласия и подтверждённой настройки авторизации. Существующие нестандартные настройки сетевой отладки не перезаписываются. Снятие флажка на рабочем ПК отключает только использование этого способа программой; для выключения режима телефона используйте «Отключить подготовку» на ПК с рабочей USB-отладкой либо настройки отладки телефона.

На рабочем ПК программа обращается только к точному адресу телефона из текущего USB-соединения. Сокет привязан к исходному адресу и индексу USB-интерфейса; чужие адреса по LAN не сканируются. Смена кабельного сеанса, интерфейса или адреса отменяет попытку. Другие ADB-подключения и VPN компьютера не изменяются.

**После перезагрузки телефона или сброса отладки может потребоваться повторная подготовка дома.** Одно обновление Windows-программы не даёт телефону отсутствующие системные права. Реальный Windows 7 и новая прошивка OnePlus в этой проверке недоступны; этот режим ещё не доказывает исправление конкретного зависания Telegram.

## Обновления

Начиная с USB Bridge 0.15.5 приложение проверяет подписанный файл обновлений примерно раз в 30 секунд, пока программа работает. На Android проверка действует при открытом приложении или активном USB-подключении; после полной остановки приложения Android не гарантирует выполнение каждые 30 секунд. При сетевых ошибках проверки становятся реже и затем возобновляются.

Доступная версия показана внутри приложения. Загрузка начинается по нажатию. Windows предлагает применить обновление после остановки USB-подключения; новая версия запускается из пользовательской папки. Android показывает обычное системное подтверждение установки. Обновления USB Bridge и WireRoute предлагаются в USB Bridge отдельно. Старые версии без этой функции нужно один раз обновить вручную.

Файл `updates/stable.json` подписан RSA-SHA256; открытый ключ закреплён в приложениях. Файлы проверяются по размеру и SHA-256; Android дополнительно проверяет пакет, версию и сертификат приложения. Запросы используют HTTPS. Неподписанный или повреждённый файл обновления не принимается. Для проверки не нужны учётная запись GitHub и токен.

**Уточнение совместимости:** в параллельной разработке уже применялся WireRoute 3.1.11 с дополнительным правилом доступа к локальному устройству. Его нельзя заменять версией 3.1.9 из этого комплекта. Android блокирует такую установку как понижение версии. Проверка обновлений USB Bridge учитывает установленный versionCode и более старый APK не предлагает.

## Windows 7 и системный доступ

Целевые системы Windows-программы — Windows 7, 8.1, 10, 11 с доступным .NET Framework. HTTPS-обновления требуют рабочей поддержки TLS 1.2 и доверенных сертификатов в системе. Старые неподдерживаемые системы не объявляются проверенными.

MIDI/USB-сеть и запуск системного помощника — разные каналы. В комплекте есть переносной `adb.exe`, но он не заменяет USB-драйвер Windows. Для обычной раздачи через Android нужен уже запущенный системный помощник: его запуск требует разрешённого ADB, доступной беспроводной отладки или root. Обход отсутствующего драйвера без этих способов не реализован. Перезагрузка телефона и некоторые переключения USB на OxygenOS останавливают помощника.

Не отключайте оптимизацию OnePlus ради этого приложения. Совместимый вспомогательный сервер исправляет отказ необязательного разрешения, сохраняя реальные ограничения Android. Официальное приложение Shizuku остаётся неизменённым.

## Telegram

«Ожидание сети» и «Соединение» означают разные этапы. Версия 0.15.4 исправила уведомление уже запущенных приложений о появлении USB-сети при рабочем системном доступе. Если Telegram уже пишет «Соединение», требуется проверка фактического пути VPN и соединения с сервером.

В WireRoute 3.1.9 раздел «Диагностика» дополнен состоянием системного доступа, USB-сети и выбора установленных вариантов Telegram для VPN. Диагностика не меняет профиль и не включает VPN сама. Работа Telegram на конкретном рабочем Windows 7 без свежей диагностики и аппаратного теста не считается подтверждённой.

## Исходники и выпуск новой версии

* `source/windows` — Windows Forms, совместимые с .NET 3.5 API.
* `source/android` — Android USB Bridge, SDK 36 / JDK 17+, Gradle wrapper.
* `source/wireroute-next` — текущий Android WireRoute. Производственная подпись настраивается локально в исключённом `keystore.properties`.
* `source/third-party` и `source/licenses` — исходники и лицензии сторонних компонентов.
* `helper-compatibility` — точечное изменение совместимости и происхождение вспомогательного сервера.
* `tools/make_update_feed.py` — создание подписанного файла обновления после сборки и проверки артефактов.

Windows: `source/build-windows.ps1`, с локальными reference assemblies .NET 3.5 через `-Net35References`. Android: `gradlew :app:assembleDebug` в ASCII-пути; WireRoute: `gradlew testReleaseUnitTest assembleRelease`. Подпись обновлений и Android-подпись остаются локальными. Сборка с другой подписью не заменит установленное приложение.

Порядок выпуска описан в `tools/RELEASING.md`. В репозитории нет пользовательских VPN-профилей, журналов телефона, закрытых ключей подписи и настроек устройств. Полные уведомления о сторонних компонентах находятся в `source/THIRD-PARTY.md` и `source/licenses`.
