# WireRoute 3.1.13 — Android

Android-клиент WireGuard с выбором приложений. Package ID и namespace: `app.wireroute.release263`; versionCode323, versionName`3.1.13-usb-handover`. Минимальный Android — API24; compile/target — API36.

Этот исходный выпуск основан на версии321 с правилом локального Station-маршрута. В323 добавлен переход уже включённого VPN с обычной сети на USB-сеанс, который подтвердил USB Bridge. Выключенный VPN сам не включается. Сохранённые профили и выбор приложений не переписываются. Подробности контракта — в [USB-BRIDGE.md](USB-BRIDGE.md).

## Установка и использование

Установите APK323 поверх прежнего WireRoute с тем же package ID и подписью. Удалять приложение перед обновлением не нужно. Если уже установлен код323 или новее, повторная установка не требуется. Пользовательские профили не входят в APK: на новом устройстве импортируйте свой обычный WireGuard-конфиг.

- В «Подключение» включается и выключается VPN.
- В «Приложения» задаётся выбор для VPN; предварительный выбор применяется кнопкой «Сохранить».
- В «Профили» выбирается и редактируется подключение.
- В «Диагностика» видны режим USB/SYSTEM, состояние сети и фактический обмен.

Для интернета компьютера нужны Windows USB Bridge0.15.7 и Android USB Bridge0.15.5. Выберите на телефоне USB-модем и нажмите «Подключить» в обоих Bridge-приложениях. VPN продолжает управляться в WireRoute, а Wi-Fi-раздача — в USB Bridge. Первый системный запрос Android подтверждает пользователь. Android разрешает один активный VPN; другая VPN-служба может конфликтовать с этим режимом.

## Сборка

Нужны JDK17, AndroidSDK36 и Gradle wrapper. На Windows используйте ASCII-путь проекта. Сборка и модульные проверки:

```powershell
.\gradlew.bat :app:testReleaseUnitTest :app:assembleRelease
```

Производственная подпись задаётся локально в исключённом `keystore.properties`. Сборка с другим ключом не заменит существующее приложение. Ключи подписи, пользовательские VPN-конфиги и настройки нельзя включать в исходный архив или релиз.

`-PusbTest` и `-PuiTest` создают отдельные тестовые пакеты; они не являются обновлением пользовательской установки. Тесты, меняющие сети, профили или VPN-сервис, выполняются только на принадлежащем тесту эмуляторе.

## Проверки и границы

После исправления отмены потерянного USB-сеанса кандидат323 пересобран: прошли113 модульных тестов в20 наборах без failures/errors/skips. Защищённые исходники хранения профилей/маршрутизации и все8 native SO совпали с базой321. Финальный APK проверен с исходной подписью и установлен поверх прежней версии без очистки профилей. Подробности — в [SOURCE-RELEASE-AUDIT.txt](SOURCE-RELEASE-AUDIT.txt).

На домашнем телефоне подтверждён переход настоящего SYSTEM VPN UP в USB/LOOPBACK UP через обычное «Подключить» на ПК, в том же процессе, с новым handshake/RX. При выключенных Wi-Fi и мобильных данных также проверены plain USB, VPN On, Telegram без «Connecting», VPN Off с возвратом plain USB и запуск plain Wi-Fi-точки. Свежей проверки второго Wi-Fi-клиента через VPN на323 не было. Во время работы наблюдался сброс USB-конфигурации; причина не установлена, кабель был переподключён. Это не доказывает работу Telegram именно на рабочей Windows7 или в корпоративной сети. Скорость конкретного кабеля и стабильность удалённого VPN-сервера модульными тестами не измеряются.
